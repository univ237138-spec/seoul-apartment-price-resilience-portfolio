# 우리집 가격체력

관심 아파트의 과거 가격 하락·회복, 거래 표본, 생활시설을 비교하는 Streamlit 대시보드입니다.

> **이 저장소에는 실데이터 파일(약 95MB)이 포함되어 있지 않습니다.** 클론한 뒤 바로 실행하면 실데이터 화면에서 파일을 찾을 수 없다는 안내가 나옵니다. 이때 **시연 화면**을 선택하거나 주소 끝에 `?mode=demo`를 붙이면 예시 데이터로 모든 기능을 볼 수 있습니다. 실데이터를 쓰려면 아래 [데이터 파일](#데이터-파일)을 참고하세요.

## 실행

현재 프로젝트에 설치된 Python에서 바로 실행할 수 있습니다. **프로젝트 최상위 폴더**에서:

```powershell
python -m streamlit run "대시보드/streamlit_app.py" --browser.gatherUsageStats false
```

브라우저에서 http://localhost:8501 을 엽니다. 실데이터가 있으면 기본 화면은 **실데이터 · 송파구 · 60㎡ 이상 85㎡ 미만 · 리센츠**입니다. 상단의 **시연 화면**을 선택하면 모든 예시 숫자가 채워진 화면을 볼 수 있습니다. `?mode=demo`로 바로 시연 화면에 접근할 수도 있습니다.

새 환경에서는 Python 3.14에서 검증된 의존성을 설치한 뒤 실행합니다. 가상환경을 사용하는 경우 활성화 없이 해당 Python을 직접 호출할 수 있습니다.

```powershell
python -m venv "대시보드/.venv"
& "대시보드/.venv/Scripts/python.exe" -m pip install -r "대시보드/requirements.txt"
& "대시보드/.venv/Scripts/python.exe" -m streamlit run "대시보드/streamlit_app.py" --browser.gatherUsageStats false
```

서버를 중지하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다. API 키·계정·데이터베이스는 필요하지 않습니다. 지도 배경은 CARTO의 외부 타일을 사용하므로 인터넷 연결이 필요하며, 지도 없이도 시설 카드로 이름과 거리를 확인할 수 있습니다.

## 사용 방법

1. 자치구·면적 구간·아파트를 선택합니다. 조건에 맞는 단지 목록이 즉시 바뀝니다.
2. **결과 보기**를 누르면 한줄 결론·가격·그래프·생활시설을 한 번에 갱신합니다.
   가격 흐름의 **가장 힘들 때**에는 최대 낙폭(MDD), **지금은**에는 고점 대비 위치를 표시합니다.
   등급 링 옆 **!** 아이콘을 클릭하거나 키보드로 선택해 Enter/Space를 누르면 산출 기준이 펼쳐집니다. 실제 방어·회복 백분위와 배점, 비교 집단 수·등수, 등급 구간과 현재 위치, 회복률 대신 고점 대비 위치를 쓰는 이유를 확인할 수 있습니다. **동점 처리·표본·계산 시점 자세히 보기**에는 반올림·하락 없음 처리와 기준 분기가 표시됩니다. ! 아이콘을 다시 누르면 닫힙니다.
3. **추가 비교 단지**에서 최대 2개를 선택합니다. 기준 단지를 포함해 최대 3개를 같은 면적·분기로 비교합니다.
   각 비교 카드의 가격 아래 **더보기**를 누르면 해당 단지의 건축연도·세대수·지상/지하 주차대수·복도유형과 최근접 시설명·직선거리가 펼쳐집니다. **접기**로 닫을 수 있으며, 원천값이 없는 항목은 ‘자료 없음’으로 표시합니다.
4. **하락분 회복률과 산출 기준 보기**에서 상세 비율과 그래프의 실제 분기 집계표를 확인합니다.
   같은 위치의 **가격 추이 / 단지 분포** 탭으로 전환할 수 있습니다. 단지 분포는 **결과 보기로 적용한 자치구·면적군**의 단지를 최대 낙폭(MDD) × 고점 대비 위치로 표시하며, 선택 단지는 초록색으로 강조합니다. 다른 구·면적군은 포함하지 않습니다. 각 좌표는 추이 그래프와 같은 계산 기준을 사용하며, 거래 부족·하락 구간 없음으로 제외한 수를 안내합니다. 세로 점선은 선택 단지를 제외한 비교 단지의 MDD 중앙값, 가로 점선은 전고점 회복 기준인 0%입니다. 오른쪽 설명은 두 지표의 비교 단지 중앙값과 선택 단지를 비교합니다. 점의 툴팁과 상세 표에서 단지별 기준 시점과 거래건수를 확인할 수 있습니다. 시연 모드에서는 예시 가격 흐름으로 분포를 계산합니다.
   추이 그래프는 가격 변화를 보기 쉽게 Y축을 자동 확대하며, 이때 **Y축 자동 확대 · 0 생략** 배지와 **// 0 생략** 표시가 나타납니다. **Y축 0부터 보기**를 켜면 같은 데이터를 0만원/㎡부터 비교할 수 있습니다.
5. **데이터 범위와 단지 정보**에서 자료 기간·제외 건수·단지 기본 정보를 확인합니다.

검색 중인 조건과 화면에 적용된 조건을 분리합니다. 결과 보기 전에는 기존 결과가 유지됩니다. 실데이터와 시연 화면은 각자의 검색·비교 상태를 기억합니다.

## 실제 데이터와 시연 데이터

지정 CSV만 읽으며 원본을 수정하거나 다른 파일을 자동 결합하지 않습니다.

`거래_단지_DATA/아파트_거래_DATA_대시보드_실데이터.csv.gz`

실제 파일은 **610,341행·88열**, **2017.01~2026.08** 계약입니다. 현재 시세가 아닙니다. 정제 후 고유 단지는 **8,963개**이며, 첫 로드에 약 **45초**가 걸립니다(이후에는 캐시가 처리하지만 서버 재시작·캐시 만료 때마다 다시 발생합니다). 그중 약 22초는 CSV 파싱 자체라, 더 줄이려면 파일 형식을 바꿔야 합니다.

| 항목 | 실데이터 | 시연 |
|---|---|---|
| 가격·거래량 | CSV에서 계산, 부분 표본 표시 | 고정 예시 시계열에서 계산 |
| MDD·회복률 | 표본 기준 충족 시만 계산 | 2021Q3~2026Q2 예시로 계산 |
| 점수·등급 | 같은 면적군 순위로 산출 (방어 20 + 회복 80) | 리센츠 64·B+, 헬리오시티 72·A, 파크리오 79·A, 문정시영 29·C+ (고정 예시) |
| 시설 | 유형별 최근접 1개, 직선거리 | 시연용 거리·개수·배치 |
| 학교·점포 전체 개수 | 집계자료 없음 | 학교 1km 5개, 장보기 2km 4곳 등의 예시 |

시연은 실제 거래·가격·입지 평가가 아닙니다. 시연 화면의 점수는 단지가 4곳뿐이라 실데이터가 쓰는 순위 산출을 적용할 수 없어 손으로 고정한 예시이며, 실데이터 등급으로 이어지지 않습니다. 시연의 리센츠 고점 3,540, 저점 2,389, 기준 가격 4,118만원/㎡에서 MDD −32.5%, 고점 대비 +16.3%, **하락분 회복률 150.2%**를 계산합니다. 최근 4개 분기 거래건수 40·40·36·89건을 합쳐 205건을 표시합니다.

## 집계와 계산 규칙

- 면적 구간: `[0,40)`, `[40,60)`, `[60,85)`, `[85,102)`, `[102,135)`, `[135,∞)`. 면적 0 이하의 행은 제외합니다.
- 단지 키: 정상 매칭 KAPT 코드를 우선 사용합니다. 미매칭이면 지역·도로명주소(없으면 번지)·단지명을 결합한 키를 사용합니다. 화면에는 거래 원본의 단지명을 표시합니다.
- 형 변환: UTF-8 BOM CSV, 문자열 식별자 보존, 가격 쉼표 제거, 계약년월·계약일 결합. `-`와 빈값은 결측으로 취급합니다.
- 해제 거래, 0 이하·비유한 가격과 면적, 잘못된 날짜, 누락된 단지명·지역은 제외합니다. 원본은 보존하며 극단적인 가격만을 이유로 자동 삭제하지 않습니다. 제외 사유별 건수는 서로 중복될 수 있습니다.
- 분기 대표가격: **각 거래의 금액 ÷ 면적**을 먼저 계산하고 **단지 × 면적 구간 × 분기**의 중위값을 구합니다.
- 완결 분기: 시작일이 자료 시작일 이후이고 최신 관측 분기보다 이전인 분기입니다. 최신 관측 분기는 항상 보수적으로 부분 분기로 취급합니다. 거래일 범위만으로 시장 전체 거래의 완전성을 보장하지 않습니다.
- 비교 기준: 데이터 전체의 최신 관측 분기를 **현재·잠정**으로 사용합니다. 현재 CSV에서는 2026년 7~8월입니다. 다만 그 분기의 거래가 3건에 못 미치면 **마지막으로 3건 이상 거래된 분기까지 기준을 물립니다**(`Snapshot.basis`). 값을 옮겨오는 것이 아니라 실제로 관측된 분기를 쓰는 것이며, 물러난 경우 카드 상단에 어느 분기를 썼는지 표시합니다. 3건 이상인 분기가 하나도 없으면 기준 가격을 비웁니다.
- 장기 지표 최소 조건: 분기당 3건 이상인 완결 분기가 4개 이상. 조건을 충족하면 최신 부분 분기도 잠정값으로 MDD·회복 계산에 포함합니다. 이는 검증된 신뢰등급이 아닌 초기 계산 조건입니다.
- 조건을 못 채우는 조합에는 **대체 화면**이 나갑니다. 없는 값을 채우는 대신 실제로 기록된 것만 보여줍니다: 마지막 실거래 1건(분기 중위값이 아닌 체결가), 첫 관측 분기 대비 마지막 관측 분기의 가격 변화, 자격 분기 수. 분모는 자료 전체가 아니라 그 조합의 거래가 처음 확인된 이후 분기 수입니다.
- 억원 환산가격: 각 시점의 ㎡당 중위가격 × 대표면적 ÷ 10,000. 대표면적은 면적 구간 상한(40·60·85·102·135㎡), 135㎡ 이상 구간은 해당 단지의 그 구간 전체 유효 거래면적 중위값입니다. 분기별 중위면적의 중위값을 사용하지 않습니다. 개별 세대의 실제 매매가격과 다를 수 있습니다.
- 거래 근거 카드의 분기 수: 전체 관측 범위의 달력상 분기 수(거래 없는 분기 포함) 중 최소 거래건수를 충족하는 완결 분기와 최신 부분 분기의 수입니다. 전체 장기 지표 산출 가능 여부는 별도의 ‘현재 상태’에 표시합니다.
- 기간 표시: 고점·저점은 해당 분기의 월 범위, 현재는 최신 분기 중 CSV가 관측한 월 범위로 표시합니다. 하락 기간은 고점→저점, 경과 기간은 고점→현재, 회복 기간은 저점→첫 고점 회복 사이의 분기 차이를 년·개월로 환산합니다.
- MDD: 시간순 가격을 누적 최고가격으로 나눈 수익률의 최솟값. 가장 먼저 발생한 최대 낙폭의 저점과 그 이전 고점을 연결합니다. 회복 이후 새 최고가를 과거 하락의 고점으로 바꾸지 않습니다.
- 하락분 회복률: `(기준 가격 − 저점) / (고점 − 저점) × 100`. 100% 이상도 그대로 표시합니다.
- 고점 대비 위치: `(기준 가격 / 고점 − 1) × 100`.
- 회복 기간: 저점 이후 최초로 기준 고점 이상을 관측한 분기까지의 분기 수. 요약 카드에는 년·개월로 환산해 표시하고, 미회복·하락 구간 없음은 숫자 대신 상태로 적습니다.
- 등급: 같은 **면적군** 안에서 두 축의 순위를 매기고 **방어 20 + 회복 80**으로 합산합니다. 방어는 MDD, 회복은 고점 대비 위치의 순위입니다. 회복 축에 하락분 회복률을 쓰지 않는 이유는 분모(고점 − 저점)가 얕은 하락에서 0에 수렴해 값이 발산하기 때문입니다. 팝업의 회복률 최댓값은 현재 데이터에서 산출 가능한 전체 지역·면적군의 단지·면적 조합을 대상으로 매번 계산합니다. 과거 분석의 예시 숫자를 고정하지 않습니다. 하락이 없던 조합은 두 축 모두 만점이며 축별 비교에서는 제외하고 총점 순위에는 포함합니다.
- 백분위: `(더 낮은 값 수 + 동점 수 × 0.5) / 비교 수 × 100`으로 자기 자신을 포함합니다. 총점 등수는 반올림 전 값의 내림차순이며 동점은 공동 순위입니다. 등급과 상위 비율은 총점 백분위로 정합니다. 각 배점과 총점은 따로 반올림하므로 표시된 합계가 1점 차이 날 수 있습니다. 시연 화면의 점수는 고정 예시이므로 실제 백분위·등수를 표시하지 않습니다.
- 등급 구간은 절대 점수가 아니라 순위입니다. A+ 상위 10%, A 25%, B+ 45%, B 65%, C+ 85%, 그 아래 C. 가중치 20/80은 데이터에서 도출한 값이 아니라 명시적으로 선택한 편집 기준이며, 척도만 데이터에서 옵니다.
- 등급 모집단은 자치구가 아니라 면적군입니다. 자치구×면적군으로 좁히면 조합이 20개 미만인 칸이 생겨 순위가 불안정해집니다.
- 관측된 하락이 없으면 MDD 0%, 회복률은 ‘하락 구간 없음’. 자료 부족이나 분모 0을 숫자 0으로 대체하지 않습니다.
- 최근 1년 거래: 기준 분기와 이전 3개 분기의 합. 자료 범위가 그 4개 분기 앞까지 닿을 때 제공하며, 현재 분기가 부분 분기이므로 잠정값입니다.
- 분기별 가격 공백은 채우거나 선으로 이어 붙이지 않습니다. 시연 데이터의 보간과 분리됩니다.
- 시설은 거래 행마다 합산하지 않습니다. 단지·입지 정보 묶음 중 최빈 묶음을 선택하고 동률이면 원본의 첫 묶음을 사용합니다. 좌표 없음과 1km 내 매핑시설 없음을 구분합니다. 거리 0m는 유효값입니다.
- 현재 시설은 거래 당시 시설 현황이 아닐 수 있습니다. 학교는 학교급 전체에서 가장 가까운 1개입니다. 1km 최근접 CSV로 시설 총개수나 2km 점포 수를 계산할 수 없습니다.

## 데이터 파일

로컬·테스트·Streamlit Cloud가 모두 같은 파일 하나를 기본으로 씁니다: `거래_단지_DATA/아파트_거래_DATA_대시보드_실데이터.csv.gz`(`housing.data.DEFAULT_CSV`). 원본 610,341행 전체(2017-01~최신월, 앱이 쓰는 컬럼만 추려 gzip 압축, 약 95MB)를 담고 있습니다. pandas가 `.gz` 확장자를 자동 인식하므로 앱 코드는 압축 여부를 신경 쓰지 않습니다.

이 파일은 용량 때문에 포트폴리오 저장소에 포함하지 않았습니다. 전처리·매핑 파이프라인(`02_거래전처리` → `03_단지매핑_입지결합`)으로 만든 원본 CSV(842MB, 압축 전)가 있으면 다음을 실행해 배포용 파일을 만들 수 있습니다.

```powershell
python 03_단지매핑_입지결합/거래_단지_매핑/build_cloud_dataset.py
```

GitHub의 파일당 100MB 제한에 여유가 크지 않습니다(현재 약 95MB). 원본 거래가 크게 늘어나면 `build_cloud_dataset.py`의 경고를 확인하고 Parquet 등으로 교체를 검토하세요.

기본 CSV 대신 다른 파일을 쓰려면 실행 전에 환경변수를 설정합니다. 파일 크기·수정 시각 변경은 캐시가 자동으로 감지해 선택 상태까지 갱신합니다.

```powershell
$env:APARTMENT_DATA_CSV = "C:/데이터/다년도_아파트_거래_입지.csv"
python -m streamlit run "대시보드/streamlit_app.py" --browser.gatherUsageStats false
```

필수 컬럼은 `시군구`, `단지명`, `전용면적(㎡)`, `계약년월`, `계약일`, `거래금액(만원)`입니다. 시설·단지 보조 컬럼이 없으면 해당 정보는 결측 상태로 표시됩니다. 주소·KAPT 컬럼은 같은 이름의 다른 단지를 구분하기 위해 유지해야 합니다. 숫자만 집계된 결과 CSV가 아니라 거래 단위 CSV를 입력합니다.

앱 실행 위치와 무관하게 기본 CSV는 앱 파일 위치에서 찾습니다. 향후 실제 점수 산식이 확정되면 지표 계산과 `Snapshot.score` 공급부를 변경하고, 시연 설정을 실제 산식으로 그대로 가져오지 않습니다.

## 코드 구조

- `streamlit_app.py`: 진입점, 캐시, 모드·검색·비교 상태 관리.
- `housing/data.py`: CSV 검증, 단지 식별, 가격 집계, 시설 대표값.
- `housing/models.py`: 데이터·지표·화면 결과 계약.
- `housing/metrics.py`: MDD·회복률·표본 조건·기준 분기(basis) 선택·설명문.
- `housing/scoring.py`: 면적군 내 순위 기반 등급(방어 20 + 회복 80).
- `housing/price_overview.py`, `price_overview_ui.py`: 지표가 나오는 조합의 가격 카드.
- `housing/sparse_overview.py`, `sparse_overview_ui.py`: 지표를 못 내는 조합의 대체 화면.
- `housing/demo.py`: 시연 고정값과 분기 시계열.
- `housing/ui.py`, `housing/visuals.py`, `style.css`: 카드, 반응형 화면, Plotly, pydeck.
- `tests/test_dashboard.py`: 산식·시연·Streamlit AppTest 검증.
- `tests/fixtures/sample_transactions.csv`: 파이프라인·AppTest가 쓰는 17행 고정 표본. 기대값을 손으로 검산할 수 있게 설계했습니다.
- `tests/browser_qa.py`: 별도 headless Chrome으로 데스크톱·모바일 스크린샷과 상호작용 확인.
- `validate_real_dataset.py`: 실제 배포 CSV로 앱이 뜨는지 확인하는 별도 스크립트.

각 지표는 값·단위·기간·출처·상태·산출 불가 사유를 보존합니다. 카드, 그래프, 비교, 설명문은 같은 `Snapshot`의 값을 사용합니다.

## 테스트

추가 테스트 패키지 없이 기본 계산·AppTest 테스트를 실행할 수 있습니다. 테스트는 배포용 CSV가 아니라 `tests/fixtures/sample_transactions.csv`만 읽으므로, 기본 CSV를 교체해도 깨지지 않고 전체가 10초 안에 끝납니다.

```powershell
python -X utf8 -m unittest discover -s "대시보드/tests" -v
```

실제 배포 CSV로 앱이 뜨는지 확인하려면 별도 스크립트를 씁니다. 61만 행을 그대로 읽으므로 1분 안팎 걸립니다.

```powershell
python -X utf8 "대시보드/validate_real_dataset.py"
```

pytest를 사용하는 경우 해당 환경에 pytest를 설치하고:

```powershell
python -m pytest "대시보드/tests/test_dashboard.py" -q
```

브라우저 테스트는 Streamlit 서버 실행 및 Chrome·Playwright가 필요합니다. 사용자 브라우저 프로필을 사용하지 않고 별도의 headless 세션을 실행합니다.

```powershell
python -X utf8 "대시보드/tests/browser_qa.py"
```

검증 이미지는 `.qa`에 저장되며 앱의 데이터로 사용하지 않습니다. `.test_deps`가 있으면 브라우저 검증 스크립트가 프로젝트 내 해당 테스트 도구를 우선 사용합니다.
