## 3. 최종 데이터 사용 시 주의사항

1. **기본 분석에는 도로명 보완 완료 파일을 사용합니다.** 취소 거래는 제거되었고 행 수는 610,341행입니다.
2. **`NO`를 단독 기본키로 사용하지 않습니다.** 필요하면 여러 거래 속성을 조합한 내부 식별키를 새로 만듭니다.
3. **핵심키가 같은 행을 일괄 중복 삭제하지 않습니다.** 동일 날짜·가격·면적·층에서 실제 복수 거래가 발생할 수 있고, 이를 구분할 `호`나 공식 거래 고유번호가 없습니다.
4. **조건부 가격 이상치 20행과 건축년도 역전 39행은 품질 플래그로 관리합니다.** 현재 근거만으로 오류나 삭제 대상으로 확정하지 않습니다.
5. **도로명 보완 3행은 대표 주소 적용 상태입니다.** 주소 단위 분석이 중요한 경우 원천기관 자료나 동·호 정보로 추가 검증합니다.
6. **CSV 재로딩 시 타입 복원 코드를 사용합니다.** CSV 파일만 다시 읽으면 날짜형·범주형·nullable 정수형이 자동으로 동일하게 복원되지 않을 수 있습니다.
